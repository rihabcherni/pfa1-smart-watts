# Smart Watts

**Smart Watts** is a web application built with **React.js**, **Laravel**, and **MySQL**, designed to provide an intelligent solution for monitoring and managing energy consumption.

## Technologies Used
- **Frontend:** React.js
- **Backend:** Laravel (PHP)
- **Database:** MySQL
